Week 01 – Synthetic Data Generation using Stable Diffusion

This folder contains the implementation and documentation for Week 01 of the
CSET419 – Introduction to Generative AI laboratory work.

In this experiment, a pretrained Stable Diffusion v1.5 model was used to
generate a synthetic image dataset from multiple textual prompts. The generated
images were saved in a structured dataset format and visualized for validation.

Contents of this folder:
- Implementation notebook (.ipynb)
- Lab report (PDF)
- Lab notes
- Generated synthetic dataset (outputs directory)

The experiment demonstrates the use of pretrained diffusion models for
synthetic data generation and dataset preparation for downstream machine
learning applications.
