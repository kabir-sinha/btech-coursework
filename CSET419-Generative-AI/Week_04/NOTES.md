# Week 04 — Lab Notes

## Key Concepts Learned
- Character-level tokenization
- Sequence modeling
- LSTM architecture for text generation
- Transformer encoder mechanism
- Positional encoding
- Autoregressive text sampling

## Practical Observations
- LSTM captures local sequential dependencies effectively
- Transformer training is parallel but requires more data
- Generated text quality depends heavily on dataset size
- Character-level models produce syntactically plausible but semantically noisy text on small corpora

## Learning Outcome
This lab provided practical understanding of sequential language modeling using both recurrent and transformer-based architectures.
