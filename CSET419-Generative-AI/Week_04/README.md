# Week 04 — Character-Level Text Generation using LSTM and Transformer

## Objective
The objective of this experiment is to implement and compare character-level text generation using Recurrent Neural Networks (LSTM) and Transformer architectures.

## Methodology
A character-level language modeling pipeline was implemented. The text corpus was tokenized at the character level and sequential data was prepared. An LSTM-based model and a Transformer-based model were trained to predict the next character in a sequence. Text generation was performed using both trained models.
