# Week 01 — Synthetic Data Generation using Stable Diffusion

## Objective
The objective of this laboratory experiment is to generate a synthetic image dataset using a pretrained Stable Diffusion model and organize the generated samples in a structured dataset format.

## Methodology
A pretrained Stable Diffusion v1.5 model from the HuggingFace Diffusers library was used to generate images from multiple textual prompts. The generated outputs were visualized and stored locally as dataset samples for verification and future machine learning applications.

## Outcome
This experiment demonstrates the use of pretrained diffusion models for synthetic dataset creation and visualization, which can be further utilized for downstream machine learning tasks.
