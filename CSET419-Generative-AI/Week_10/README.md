# Week 10 – Sequential Data Generation using LSTM and Transformer

## Objective
To implement sequence generation using LSTM and Transformer models with positional encoding.

## Concepts Covered
- Tokenization
- Sequence modeling
- LSTM (Recurrent Neural Networks)
- Transformer architecture
- Positional Encoding
- Text generation

## Implementation Details
- Dataset: Custom text corpus
- Sequence Length: 5
- Embedding Size: 64
- Epochs: 200
- Loss Function: CrossEntropyLoss
- Optimizer: Adam

## Models Used

### LSTM
- Captures sequential dependencies
- Maintains hidden states over time

### Transformer
- Uses self-attention mechanism
- Includes positional encoding for sequence order

## Outputs
- Generated text using LSTM
- Generated text using Transformer

## Files
- CSET419_GenAI_Lab10.ipynb
- E23CSEU1343-Kabir-CSET419-Lab10.pdf

## Conclusion
LSTM captures sequential dependencies effectively, while Transformer improves parallel processing and captures global context using attention. Positional encoding helps retain sequence order information.
