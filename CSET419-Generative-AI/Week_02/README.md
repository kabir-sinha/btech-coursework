# Week 02 — GAN-based Synthetic Image Generation using MNIST

## Objective
The objective of this laboratory experiment is to implement a Generative Adversarial Network (GAN) to generate synthetic handwritten digit images using the MNIST dataset.

## Methodology
A fully connected Generator and Discriminator architecture was implemented using PyTorch. The GAN model was trained on the MNIST dataset for multiple epochs using adversarial training. Generated samples were periodically visualized to monitor training performance and final synthetic outputs were saved for evaluation.

## Outcome
The experiment demonstrates the implementation of GAN architecture for synthetic image generation and provides practical understanding of adversarial training dynamics using the MNIST dataset.
