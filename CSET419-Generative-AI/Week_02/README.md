# Week 02 — GAN-based Synthetic Image Generation using MNIST

## Objective
The objective of this laboratory experiment is to implement a Generative Adversarial Network (GAN) to generate synthetic handwritten digit images using the MNIST dataset.

## Methodology
A fully connected Generator and Discriminator architecture was implemented using PyTorch. The GAN was trained on the MNIST dataset for multiple epochs using adversarial training to generate realistic digit samples.

## Files Included
- CSET419_GenAI_Lab2.ipynb — Implementation notebook
- E23CSEU1343-Kabir-CSET419-Lab2.pdf — Lab report
- synthetic_dataset.zip — Generated image samples

## Outcome
The experiment demonstrates the capability of GANs to learn the distribution of handwritten digits and generate synthetic samples useful for data augmentation and generative AI applications.
