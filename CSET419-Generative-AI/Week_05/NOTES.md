# Week 05 — Lab Notes

## Key Concepts Learned

- Encoder–decoder architecture for image reconstruction  
- Convolutional and transposed convolutional networks  
- Image-to-image translation fundamentals  
- Training using L1 reconstruction loss  
- Visual evaluation of generated outputs  

## Practical Observations

- GPU acceleration significantly improves training time  
- L1 loss provides stable reconstruction learning  
- Deeper encoders improve feature extraction quality  
- Visual comparison is important for generative tasks  

## Learning Outcome

This lab provided hands-on experience with convolutional encoder–decoder networks for image reconstruction and strengthened understanding of image-to-image translation workflows in generative AI.
