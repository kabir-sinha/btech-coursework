# Week 09 Notes — Sequence Generation

Sequential Data:
- Data where order matters
- Example: text, speech, time series

Sequence Models:
- Predict next element based on previous inputs

LSTM:
- Type of RNN
- Maintains long-term dependencies
- Uses hidden states and memory cells

Transformer:
- Uses attention mechanism
- Processes sequences in parallel
- Captures relationships between words

Tokenization:
- Converting words into numbers

Sequence Generation:
- Model predicts next word iteratively
- Uses seed input to generate text

Observations:
- LSTM produces structured outputs
- Transformer captures flexible patterns
- Both models generate meaningful sequences

Key Insight:
Sequence models learn patterns in ordered data and can generate new sequences based on learned representations.
